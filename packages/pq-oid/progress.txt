### Task 8: Implement OID Encoding (TDD - GREEN) - DONE
- Created `src/encoding.ts` with DER encoding/decoding functions for OIDs
- Implemented `encodeOid(oid: string): Uint8Array`:
  - Parses OID string in dotted notation (e.g., "2.16.840.1.101.3.4.4.1")
  - Combines first two arcs as per DER rules: (first * 40) + second
  - Encodes each arc using base-128 with high bit set on continuation bytes
  - Validates OID format: requires at least 2 arcs, numeric values only
  - Validates first arc (must be 0, 1, or 2)
  - Validates second arc (must be <= 39 when first arc is 0 or 1)
- Implemented `decodeOid(bytes: Uint8Array): string`:
  - Decodes DER bytes back to OID string
  - Handles base-128 decoding with continuation bytes
  - Splits combined first byte into first two arcs
  - Throws for empty bytes or incomplete multi-byte encoding
- Helper function `encodeArc(value: number)` handles base-128 encoding for arc values
- All tests in `tests/encoding.test.ts` should now pass (GREEN phase)
